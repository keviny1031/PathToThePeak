# Pokemon TCG Live Practice Tracker

A local-first practice tracker for recording Pokemon TCG Live wins and losses by deck.

## Run

Open `index.html` in a browser. The app stores decks and game history in the browser's `localStorage`.

## Features

- Add, rename, select, and delete decks.
- Log wins or losses for the selected deck on any date.
- Save opponent deck titles and pick them from a dropdown while logging games.
- Review recent game history and remove individual entries.
- See overall record, win rate, and per-deck performance.
- View daily win percentage as a line chart for all decks or a single deck.
- Compare win rate by matchup across saved opponent deck titles.
